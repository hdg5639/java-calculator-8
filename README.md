# java-calculator-precourse

# 문자열 덧셈 계산기
## 요구 사항
### 기능
#### 1. 입력한 문자열에서 숫자를 추출하여 더하는 계산기 구현
- **구분자**
  1. 기본 구분자: 쉼표(,), 콜론(:)
  2. 커스텀 구분자: "//"와 "\n" 사이의 문자
- **예외 처리**
  1. **IllegalArgumentException** 발생 후 종료

### 입출력 요구사항
#### 입력
- 구분자와 양수로 구성된 문자열
#### 출력
- 덧셈 결과
```
결과 : 6
```
### 실행 결과 예시
```
덧셈할 문자열을 입력해 주세요.
1,2:3
결과 : 6
```
